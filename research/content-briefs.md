# Phase 3 — Content Benchmarks & Briefs
**Word-count benchmark method:** median of top-5 rankers per cluster (observed via live SERPs; competitor service pages run ~900–1,400 words, cost guides ~1,800–2,400). Targets below.

## Global page template (all service pages)
H1 (keyword + CTA) → Intro 150–200 words (keyword + location in first 100) → Service details (H2/H3, semantic keywords) → Benefits → Common problems → Process (4–6 steps) → Why choose us → Gallery (3–6 images + captions) → FAQ (5–7 PAA questions) → Related services → Final CTA (tel: + quote form).
On-page: title 50–60 chars, meta 150–160 chars (keyword + benefit + CTA + phone), breadcrumbs + BreadcrumbList, JSON-LD (Service + FAQPage + LocalBusiness), 3–5 internal links, "Last updated" date.
